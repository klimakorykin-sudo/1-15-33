# 🏗️ Архитектура

## Слои (FSD)
1. `app` — инициализация
2. `pages` — страницы
3. `widgets` — крупные блоки
4. `features` — фичи
5. `entities` — сущности
6. `shared` — общее

## Правило
Слои зависят только сверху вниз.
`pages` не знают о `pages`.
`features` не знают о `features`.

## Сложность
View — тупой.
Store — тупой.
Вся логика — в слушателях.
